## Failure-Mode Taxonomy (per condition)

- **A**: no cross-session information → fails (expected).
- **D**: under 2K token ceiling, oldest-first truncation loses the design-bearing message → structurally reproducible failure.
- **B**: memory extraction works; failure mode is *retrieval* (semantic search misses the design memory in seed 3).
- **C**: extraction works; failure mode is *fidelity of page-relevant string* (C2/C3 said "categories" instead of preserving the exact key `reports`).

## Causal-channel verdict

C1 is a genuine causal trace: the serialized C-state included the exact response
shape (`'reports'` list + `page_size=7`), and S2 implemented it verbatim → tests pass.
C2/C3 fail *upstream*, in extraction phrasing, not in representation structure or
in the agent loop.

## Interpretation (held separate)

Observations only; not accepted as evidence for/against the protocol hypotheses.

- A is behaviorally correct as negative control.
- D's truncation behavior is mechanical and expected.
- B chooses information effectively 2/3 but has retrieval variance.
- C is highly token-efficient (~700 tokens vs D's ~1900) but extraction wording
  fidelity is the binding constraint at this scale.

conditions and evaluation philosophy. Central question: does structured cross-session
